How to use this help

F1 opens the topic for where you are. There is also search, a language switch, printing and a support report.

how-toNew in 1.4.0

This help travels inside the application. It needs no internet and answers from wherever you are.

Opening it#

  • F1 — opens the topic for the screen you are on. With a dialog open it opens the dialog's topic, not the tab behind it.
  • **The ? button** in the top bar — opens the topic for the active tab.
  • The small ? marks on some headers — open the topic for that particular section.
  • The gear at the top left → "Help", which opens the front page, and "About Raphael", which gives your version, the build date, and which version this help covers.

F1 from where you are, not from an index

Searching an index requires knowing what the thing you want is called. A dispatcher with a patient on the phone is in no position to guess the name of a section.

So F1 does not open the front page: it opens the topic for what is in front of you. Where you are is the one thing you know for certain.

In a window, or inside the application#

The help opens in its own window, so you can move it to the second monitor and keep working with the trip in front of you. It is not modal: the application keeps responding underneath.

  • The button at the top right of the panel puts it back in a tab, and from the tab it pulls it out to a window again. It is the same panel, so you lose neither the page nor your place in it.
  • The window remembers where you left it: position, size, and whether it was maximised. Unplug a monitor and it comes back to a screen that exists, instead of opening where there is nothing.
  • Closing the help closes it. It does not tuck itself into a tab: where it lives is decided by the dock button, never by the close button. Next time it opens where you actually left it.

Searching#

Press **/** at any time to jump to the search box. Search for what you would say out loud: the search understands "bell", "notice", "down" and other office words, as well as the ones on screen.

Use ↑ ↓ to move through the results and Enter to open the highlighted one.

Language#

The ES / EN button at the top right switches the help's language. Opened from the application, it already comes in the language you have set in Raphael.

Printing#

"Print" produces the topic you are reading, without the contents rail or the menus. Useful for pinning a procedure next to a workstation.

Which version it covers#

The foot of every page says which version of Raphael Desktop this help covers, and when it was updated.

If the application is ahead, the help says so in a band at the top instead of keeping quiet. Help that describes the previous version without warning is worse than no help, because it is believed.

Copy report for support#

The button at the foot copies, in one go, the version, the build, your role, the language, the topic you are reading, and the notification channel status.

Pasting it into the email saves the first three questions support is going to ask you.

What can go wrong#

F1 opens nothing. Click inside the Raphael window to give it focus and try again.

An "open it for me" link is greyed out. Those links run actions in the application, so they only work with the help open inside Raphael. In a browser they do nothing.
