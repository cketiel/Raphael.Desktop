Space type

The space the patient occupies in the vehicle. It carries load and unload times, so it is not a label: it is planning data.

reference

The space type is the space the patient occupies inside the vehicle: seated, in a wheelchair, on a stretcher.

It is not a label#

Every space type carries a load time and an unload time. That is what makes it planning data rather than a classification: loading a patient in a wheelchair does not take as long as loading somebody who walks, and the route is calculated with those minutes inside it.

A trip with the wrong space type does not produce an error. It produces a route with the wrong timings, which is worse, because nobody finds out until the driver is running late.

Capacity#

Every space type belongs to a capacity type, and that is what decides whether a given vehicle can carry it. A vehicle with no stretcher position is not an option for a stretcher trip, however free it happens to be.
